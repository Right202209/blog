# 前端样式对齐说明

当前主题对齐 `Right202209.github.io` 的 `optimization-patch` 分支。此前的纸纹、朱印、衬线字体和 GSAP 浮动装饰已由统一的深色样式取代。

| 主页元素 | 博客实现 |
| --- | --- |
| 深灰径向渐变 | 全站固定背景，色值来自主页 |
| Droit 圆形头像 | 本地复制头像，使用相同白色描边 |
| Droit 名称与签名 | 首页居中展示；导航、页脚沿用同一身份 |
| 灰白文字与细分隔线 | 导航、笔记列表、元信息和目录统一使用 |
| 橙色交互色 | 链接、焦点、最新标记与选中状态 |
| 图标式导航 | 本地 SVG 图标，无远程字体依赖 |
| 简单入场过渡 | CSS 动画，支持减少动态效果 |

长文使用系统无衬线字体和暗色代码高亮。代码、表格和公式的溢出在内容容器内处理。移动端目录默认折叠，笔记侧栏移到列表之后。

全站样式变量位于 `_sass/_shell.scss`，具体结构与验证范围见 [DESIGN.md](../DESIGN.md)。构建命令为 `bundle exec jekyll build --strict_front_matter`。
