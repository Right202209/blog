## 1. 安装 Git

### 1.1 Windows
1. 下载：[Git for Windows](https://gitforwindows.org/)。
2. 安装选默认即可。
3. 验证安装：
   ```bash
   git --version
   ```
   有版本号就说明成功。

### 1.2 macOS
```bash
brew install git
git --version
```

### 1.3 Linux（以 Ubuntu 为例）
```bash
sudo apt-get update
sudo apt-get install git
git --version
```

## 2. 基础配置

我只记两行：
```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

看当前配置：
```bash
git config --list
```

## 3. 基本概念（速记）

- **仓库**：项目目录 + 历史记录
- **暂存区**：待提交的缓冲区
- **提交**：一次快照
- **分支**：并行线路（通常 `main`/`master`）

---

## 4. 常用命令

### 4.1 初始化仓库
```bash
git init
```

### 4.2 克隆仓库
```bash
git clone <仓库地址>
```
自定义目录名：
```bash
git clone <仓库名称> <本地名称>
```

### 4.3 查看仓库状态
```bash
git status
```

### 4.4 添加到暂存区
```bash
git add <文件名>       # 添加指定文件
git add .              # 添加所有修改的文件
```

### 4.5 提交更改
```bash
git commit -m "提交信息"
```

### 4.6 查看日志
```bash
git log
```

### 4.7 远程仓库操作
- 添加远程：
  ```bash
  git remote add origin <仓库地址>
  ```
- 推送：
  ```bash
  git push origin <分支名>
  ```
- 拉取：
  ```bash
  git pull origin <分支名>
  ```

### 4.8 分支操作
- 新建：
  ```bash
  git branch <分支名>
  ```
- 切换：
  ```bash
  git checkout <分支名>
  ```
- 合并：
  ```bash
  git merge <分支名>
  ```

---

## 5. 基本工作流程

1. 初始化或克隆
2. 修改文件
3. `git add <文件名>`
4. `git commit -m "提交信息"`
5. 需要同步就 `git push origin <分支名>`

---

## 6. 其他常用命令

### 6.1 查看差异
```bash
git diff
git diff --cached
```

### 6.2 回退操作
```bash
# 回退到上一个提交（保留改动）
 git reset --soft HEAD^

# 回退并丢弃改动（确认不需要）
 git reset --hard HEAD^
```

### 6.3 删除文件
```bash
git rm <文件名>
git commit -m "删除文件"
```

## 7. 连接 GitHub 等代码托管平台

### 7.1 创建 GitHub 账号
先注册：[GitHub 官网](https://github.com/)。

### 7.2 生成并配置 SSH 密钥

#### 7.2.1 生成 SSH 密钥
```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```
按提示存储到 `~/.ssh/`（默认即可），可设置密码或留空。

生成文件：
- `id_ed25519`: 私钥
- `id_ed25519.pub`: 公钥

#### 7.2.2 添加到 SSH 代理
```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_rsa
```

#### 7.2.3 添加到 GitHub
```bash
cat ~/.ssh/id_rsa.pub
```
复制内容 → **Settings** → **SSH and GPG keys** → **New SSH key**。

#### 7.2.4 测试连接
```bash
ssh -T git@github.com
```
看到 “Hi username! …” 就说明成功。

### 7.3 绑定远程仓库
```bash
git remote add origin git@github.com:username/repository.git
git remote -v
```

### 7.4 推送到 GitHub
```bash
git push -u origin main
```
默认分支是 `master` 就改成 `master`。

后续同步：
```bash
git add .
git commit -m "更新信息"
git push origin main
```

### 7.5 克隆仓库到本地
```bash
git clone git@github.com:username/repository.git
```

### 7.6 设置全局 GitHub 信息（可选）
```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱"
```

### 7.7 Windows 额外配置
如果用 Git Bash 或 PowerShell，注意 `HOME` 环境变量和 `~/.ssh` 路径正确，避免找不到密钥。
