## 1. 环境准备

更新软件源并安装必要依赖：


sudo apt update && sudo apt upgrade -y
sudo apt install zsh git curl -y


设置 Zsh 为默认 Shell（**无需 sudo** ，注销或重启生效 ）：


chsh -s /bin/zsh


## 2. 安装 Oh My Zsh

安装过程中如提示覆盖 `.zshrc`，请选择同意。
